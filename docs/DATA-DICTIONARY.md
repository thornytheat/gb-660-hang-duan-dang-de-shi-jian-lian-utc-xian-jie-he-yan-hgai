# 数据字典

- run_id：规则版本与输入 SHA-256 前 12 位组成的稳定批次标识。
- line_no：从 1 开始的物理来源行号，不因隔离或排序改变。
- business_key：本项目声明的业务唯一键，始终按字符串存储。
- reason_code：隔离原因的稳定英文编码。
- accepted：进入业务计算的记录数。
- quarantined：保留证据但不参与业务计算的记录数。
- 数值：金额、税额、用量和权重使用 Decimal；对外序列化为字符串。
- 时间：存储为带偏移的 ISO 8601，分桶使用半开区间。
- 空值：缺失键、空串和业务哨兵分别记录。
- 幂等：完整输入字节与规则版本相同则复用 run_id，不新增结果。

## M7 计费对账

- sortie（架次）：一次实际起飞的计费单位。架次键 = 执飞航班号 + 航班日期 + 出发/到达机场 + 实际起飞时刻 + 航班性质（NORMAL/EXTRA）。
- 共享航班：营销号通过共享关系映射到执飞号后并入同一架次，一架次只收一次费，架次记录保留全部原航班号与物理行号。
- 加班机：flight_nature=EXTRA 参与架次键，同航线同刻与正常班各自独立计费。
- UNVERIFIED：航段缺执飞航班号且无共享映射时的状态，不猜测、不自动并单、不产生计费架次，进入未结清清单；POSSIBLE_DUPLICATE_SORTIE 仅为人工复核提示。
- ALREADY_BILLED：架次键在历史批次已收费时的状态，本批不重复计费。
- 费用：Decimal 字符串存储；按执飞号航司二字码匹配 fee_schedule，缺省 1200.00。
- 计费 run_id：`billing-rules-1-` + 规范化 JSON 输入 SHA-256 前 12 位；同输入重跑整批复用。
- billing_sorties 对 charged=1 的 sortie_key 建部分唯一索引，作为跨批次防重复收费的数据库级防线。
